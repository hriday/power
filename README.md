# How Big Is a Gigawatt?

A plain-language, interactive guide to electric power: watts to gigawatts, light bulbs to nuclear plants, and how much a data centre really uses compared to Red Deer, Calgary and Toronto.

**See the site at [power.moosha.org](https://power.moosha.org).**

## What's inside

- **The ladder** — a scale of power from a light bulb up to a nuclear plant
- **Cities** — how a data centre's draw compares to real cities
- **Data centre lab** — build a data centre and see what it needs
- **Power vs energy** — the difference between watts and watt-hours, plus water use
- **Headline decoder** — make sense of the numbers in the news

## Running locally

It's a static site with no build step. Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server
```
